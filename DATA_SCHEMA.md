# Data Schema Documentation

This document describes the data schema for files generated by the PUMA offline pipeline.

`run_pipeline.sh` writes these files flat inside `<base_dir>` with the simplified
names shown in parentheses below.

## Pipeline Overview

```
run_vllm.py                → answers.json                     (Step 1a; or your input)
       ↓
separate_steps.py          → steps.json (questions_with_steps) (Step 1b)
       ↓
embed_and_filter_steps.py  → filtered_steps.json              (Step 1.5, Redundancy Detector)
       ↓
gen_trial_answers.py       → trial_answers.json               (Step 2)
       ↓
extract_final_candidates.py → final_candidates.json           (Step 3)
       ↓
gen_prefixed_answers.py    → prefixed_answers.json            (Step 4)
       ↓
statistics_puma.py         → statistics.txt                   (Step 5)
```

---

## 0. answers.json

**Generated by**: `run_vllm.py` (Step 1a) — or supplied directly as pipeline input.

**Description**: Full chain-of-thought responses produced by the reasoning model.

| Field | Type | Description |
|-------|------|-------------|
| `question` | string | The original question text |
| `reasoning` | string | The model's `<think>` reasoning text |
| `raw_response` | string | The answer text after `</think>` **only** — it does *not* include `reasoning` (the two are disjoint; token stats sum them, so do not duplicate the reasoning here). Used as the segmentation fallback when `reasoning` is empty |
| `model_answer` | string | The model's extracted answer |
| `ground_truth_answer` | string | The correct answer (used for accuracy) |

---

## 1. questions_with_steps.json

**Generated by**: `separate_steps.py`

**Description**: Original questions with reasoning split into steps.

| Field | Type | Description |
|-------|------|-------------|
| `question` | string | The original question text |
| `reasoning_steps` | list[string] | List of reasoning steps extracted from the original response |
| `ground_truth_answer` | string | The correct answer |
| `model_answer` | string | The model's original answer |
| `reasoning` | string | Full reasoning text (before splitting) |
| `raw_response` | string | Answer text after `</think>` only (disjoint from `reasoning`) |

---

## 2. trial_answers.json

**Generated by**: `gen_trial_answers.py`

**Description**: Trial answers generated at each reasoning step for each question.

| Field | Type | Description |
|-------|------|-------------|
| `question_idx` | int | 1-indexed question number |
| `stopped_len` | int | Number of reasoning steps used as prefix (1 to original_len) |
| `original_len_reasoning_steps` | int | Total number of reasoning steps in original response |
| `question` | string | The question text |
| `reasoning_prefix` | string | Concatenated reasoning steps (first `stopped_len` steps) |
| `model_response` | string | Raw trial answer text generated by the model |
| `final_answer` | string | Parsed answer extracted from model_response (content inside `{...}`) |
| `count_reasoning_tokens` | int | Token count of `reasoning_prefix` |
| `count_generated_tokens` | int | Token count of generated trial answer |
| `confidence` | float | Geometric mean of answer token log-probabilities: `exp(mean(log_probs))` |
| `count_answer_tokens` | int | Number of tokens in the answer portion only |
| `new_thinking` | bool | Whether `<think>` appeared in trial answer (indicates model wanted more reasoning) |
| `success` | bool | **Whether generation succeeded (NOT answer correctness)** |

---

## 3. final_candidates.json

**Generated by**: `extract_final_candidates.py`

**Description**: Selected stopping points using two-stage detection (confidence + consistency).

**Inherits all fields from trial_answers.json**, plus:

| Field | Type | Description |
|-------|------|-------------|
| `generated_trial_answers` | int | Number of trial answers generated until the stopping point was confirmed |
| `tokens_trial_answers` | int | Total tokens spent on all trial answers (sum of `count_answer_tokens` for each) |

### Selection Algorithm

Two-stage detection with parameters (script defaults shown; the released
`configs/*.conf` use the paper values `confidence_threshold=0.98`, `epsilon=0.03`):
- `confidence_threshold` (default: 0.96)
- `epsilon` (default: 0.05)
- `consecutive` (default: 2)

**Stage 1 (High Recall)**: Find first point where `confidence >= confidence_threshold`

**Stage 2 (High Precision)**: Verify `consecutive` points have:
1. Same extracted answer
2. Confidence within epsilon of first point: `conf[i] >= conf[0] - epsilon`

---

## 4. prefixed_answers.json

**Generated by**: `gen_prefixed_answers.py`

**Description**: Final answers generated using the selected reasoning prefix.

| Field | Type | Description |
|-------|------|-------------|
| `question_idx` | int | 1-indexed question number |
| `stopped_len` | int | Number of reasoning steps used as prefix |
| `original_len_reasoning_steps` | int | Total reasoning steps in original |
| `saved_steps` | int | Steps saved: `original_len - stopped_len` |
| `question` | string | The question text |
| `reasoning_prefix` | string | Reasoning prefix used for generation |
| `model_response` | string | Generated response after the prefix |
| `final_answer` | string | Parsed answer from `\boxed{...}` in response |
| `count_reasoning_tokens` | int | Token count of reasoning prefix |
| `count_generated_tokens` | int | Token count of generated response |
| `total_tokens` | int | `count_reasoning_tokens + count_generated_tokens` |
| `generated_trial_answers` | int | Number of trial answers generated (from final_candidates) |
| `tokens_trial_answers` | int | Total trial answer tokens (from final_candidates) |
| `confidence` | float | Confidence of the final answer |
| `new_thinking` | bool | Whether extra `<think>` appeared in response |
| `success` | bool | Whether generation succeeded |

## Key Metrics Computed by statistics_puma.py

| Metric | Formula | Description |
|--------|---------|-------------|
| **CR (excluding trial answers)** | `compressed_tokens / original_tokens` | Compression rate without trial answer overhead |
| **CR (including trial answers)** | `(compressed_tokens + trial_answer_tokens) / original_tokens` | True compression rate with all overhead |
| **Original Accuracy** | `correct_original / total` | Accuracy of full reasoning |
| **Compressed Accuracy** | `correct_compressed / total` | Accuracy after early stopping |

### Note on Answer Correctness

The `success` field in all files indicates **generation success**, not answer correctness.

Answer correctness is computed in `statistics_puma.py` by comparing:
- `final_answer` (from compressed data)
- `ground_truth_answer` (from original data)

## Confidence Calculation

```python
def compute_geometric_confidence(log_probs: List[float]) -> float:
    """
    Geometric mean of token probabilities.

    confidence = exp(mean(log_probs))
              = (p1 * p2 * ... * pn) ^ (1/n)

    Range: [0, 1], higher = more confident
    """
    if not log_probs:
        return 0.0
    avg_log_prob = sum(log_probs) / len(log_probs)
    return math.exp(avg_log_prob)
```

Only the **answer tokens** (not the full trial answer) are used for confidence calculation, as this better reflects model uncertainty on the actual answer.
